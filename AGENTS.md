# AGENTS.md

Terraform IaC for a static website on AWS (S3 + CloudFront, optional ACM + Route53).
All infrastructure code lives under `terraform/`. Docs are in Spanish (`README.md`, `terraform/README.md`).
There are no tests, no CI workflows (no `.github/`), no package manager, and no linter.

## Where to run commands

Every Terraform command runs from the environment directory, **not** the repo root:

```bash
cd terraform/environments/prod
```

## Prerequisites

- Terraform >= 1.9.0 (`versions.tf` pins `required_version = ">= 1.9.0"`)
- AWS provider `~> 6.0`; exact resolution is locked in `.terraform.lock.hcl` (committed, aws 6.67.0)
- AWS credentials **outside the repo**: AWS CLI profile (`~/.aws/credentials`), `AWS_ACCESS_KEY_ID`/`AWS_SECRET_ACCESS_KEY`/`AWS_SESSION_TOKEN`/`AWS_PROFILE` env vars, an IAM role, or GitHub Actions OIDC (planned, not yet configured)
- Never commit access keys, secrets, or credentials in `.tf` or `terraform.tfvars`

## First-time setup (required before any command)

```bash
cd terraform/environments/prod
cp terraform.tfvars.example terraform.tfvars   # terraform.tfvars is gitignored
# Edit terraform.tfvars if needed (bucket_name_prefix, domain_name, route53_zone_*)
export AWS_PROFILE=mi-perfil   # or set AWS_* env vars
```

## Standard command order

```bash
terraform init      # downloads providers; creates .terraform/ (not committed)
terraform validate  # syntax + consistency check
terraform plan      # review changes before applying
terraform apply     # confirm after reviewing the plan
terraform output    # bucket names/ARNs, CloudFront domain, ACM ARN
```

## Formatting

Run from `terraform/`:

```bash
terraform fmt -check -recursive
```

## Things an agent is likely to miss

- **Two AWS providers**: the default provider uses `var.aws_region` (default `us-east-1`); a second provider `aws.us_east_1` is hardcoded to `us-east-1` because ACM certificates used by CloudFront must be issued there. The ACM module is always invoked with `providers = { aws.us_east_1 = aws.us_east_1 }`.
- **Local state only**: state lives in `terraform.tfstate` in the environment directory; it is excluded by `terraform/.gitignore` and must never be committed. No remote backend (S3/DynamoDB) exists yet — it is only sketched in `terraform/README.md`.
- **`.terraform.lock.hcl` is committed**: do not edit it manually; it is regenerated by `terraform init`.
- **Bucket names are globally unique in AWS**: default `<project_name>-prod-<purpose>` (e.g. `object-storage-prod-activos`). If a name collides, set `bucket_name_prefix` in `terraform.tfvars`.
- **Custom domain is optional**: `domain_name = null` (default) means CloudFront uses its default domain and certificate; the `acm` and `route53` modules use `count = 0` and create nothing. If you set `domain_name`, you must also set `route53_zone_id` or `route53_zone_name` (an existing public Route 53 hosted zone).
- **`test-content/`** (`index.html`, `assets/`) is sample static content. Nothing in the repo automates uploading it to the `activos` bucket; do so manually via the AWS console/CLI after `apply`.
- **Do not guess tooling**: there are no npm/node/python projects, no test runner, no lint config, no CI pipeline, and no `opencode.json`. Do not invent `npm test`, `pytest`, or GitHub Actions steps.
